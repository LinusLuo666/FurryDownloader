# FurryDownloader v6 人工验收清单

## 画师列表

- [ ] 首次启动时列表为空。
- [ ] 添加两个画师后关闭并重新打开程序，两个画师仍在列表中。
- [ ] 重复添加同一画师（包括大小写变化或带下划线输入）不会产生重复条目。
- [ ] 删除选中画师后，重新打开程序确认删除结果已保存。
- [ ] 点击一次“更新列表”会按列表顺序处理所有画师，而不是只处理输入框中的名字。

## 下载、去重和描述

- [ ] 更新时每个画师都会处理 `gallery` 和 `scraps`。
- [ ] 两个画师的图片分别保存在各自的画师目录，不会互相覆盖。
- [ ] 每个作品的描述出现在画师目录下的 `descriptions` 子目录，文本可读且换行正常。
- [ ] 第二次更新不会重新下载已经存在的图片，但会保留或刷新描述文件。
- [ ] 删除 `download-index.xml` 后再次更新，已存在的图片不会被重复下载，并会重新登记索引。

## 登录

- [ ] 点击“登录FA”，在 WebView2 窗口中完成 FA 登录后，窗口能在取得身份 Cookie 后关闭。
- [ ] 登录成功后点击“更新列表”，需要登录的画师页面和图片请求可以正常访问。
- [ ] 清空或移除 WebView2 Runtime 后再次点击登录，会显示明确的 Runtime 安装提示。

## 异常和停止

- [ ] 列表中第一个画师不存在时，第二个画师仍继续更新，日志显示失败画师和最终汇总。
- [ ] 更新过程中点击“停止”后，不再加入新的详情任务，已经加入的图片任务最终结束。
- [ ] 损坏 `artists.xml` 或 `download-index.xml` 后启动，程序可以继续运行并生成 `.bak` 备份，不删除图片。
