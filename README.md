# Fa图片批量下载器
用于根据作者名批量下载[furaffinity](https://www.furaffinity.net)网站的图片。

![界面](./images/界面.jpg)

## 使用方法
1. 选择图片根目录。
2. 在输入框填写画师名，点击“添加”；重复画师不会重复加入列表。
3. 重复添加需要维护的画师。
4. 点击“登录FA”，在内置浏览器中完成 FA 登录。
5. 点击“更新列表”，程序会按列表顺序更新所有画师的 `gallery` 和 `scraps`。
6. 图片保存在“根目录\画师名”下，作品描述保存在对应的 `descriptions` 子目录。

列表会自动保存，重新打开程序后仍会保留。更新期间可以点击“停止”；当前已加入的图片任务会等待结束，不再继续加入新的详情任务。

部分作者的内容需登录后才可查看，请先登录 FA。登录信息会缓存下来，以供下次使用；登录窗口使用 WebView2，因此运行环境需要安装 Microsoft Edge WebView2 Runtime。

下载过的图片 URL 会写入索引。重复更新时会跳过已下载图片，同时刷新对应的描述文件；即使索引缺失，只要本地图片已存在，也会登记并跳过重复下载。

程序数据目录在“我的文档\FaDownloader”：

- `artists.xml`：画师列表。
- `download-index.xml`：图片 URL 到本地路径的去重索引。
- `cookie.txt`：登录后的请求 Cookie。
- `WebView2`：内置浏览器的登录会话数据。

如果 XML 文件损坏，程序会尝试生成同名 `.bak` 备份，并从空列表或空索引继续运行，不会删除已经下载的图片。
